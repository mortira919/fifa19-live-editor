# FIFA 19 Live Editor

Редактор базы FIFA 19 прямо во время игры. Он читает таблицы из памяти запущенной игры и пишет изменения обратно, поэтому правка сразу видна в загруженной карьере, без редактирования сейва. Интерфейс открывается в браузере: свернул игру через Alt+Tab, поменял, вернулся.

Для FIFA 19 не было своего Live Editor, как у Aranaktu для FIFA 20–23 и FC 24–26. Была только таблица Cheat Engine. Этот проект закрывает дыру для тех, кто до сих пор играет карьеру в FIFA 19.

## Что нужно

- Windows 10 или 11.
- Python 3.10 или новее с python.org. При установке отметь «Add python.exe to PATH». Сторонние библиотеки не нужны.
- FIFA 19 для ПК. Патчи кода (тайм-финишинг, режим без скаутинга, точные OVR и POT) проверены только на `FIFA19.exe` версии 19.0.3865658. На другой версии редактор просто покажет их как недоступные, а редактирование базы продолжит работать.

## Запуск

**Вручную.** Запусти игру, потом `Запуск редактора.bat`. Откроется браузер с адресом `http://127.0.0.1:8919/`. Через 10–20 секунд после главного меню игры редактор найдёт базу.

**Вместе с игрой из Steam.** Если FIFA 19 добавлена в Steam как сторонняя игра, открой её свойства и поменяй три поля:

| Поле | Значение |
|---|---|
| Расположение | `"C:\Python313\pythonw.exe"` (путь к своему `pythonw.exe`) |
| Рабочая папка | папка редактора, например `"C:\FIFA 19 Live Editor\"` |
| Параметры запуска | `le.py --game "D:\Games\FIFA 19\FIFA19.exe"` (путь к своей игре) |

Кнопка «Играть» тогда запускает игру и редактор вместе. У редактора нет консольного окна, случайно закрыть его нельзя. Через минуту после выхода из игры он закрывается сам. Браузер не открывается, чтобы не выкидывать тебя из полноэкранной игры, поэтому сохрани `http://127.0.0.1:8919/` в закладки.

Если Windows не даёт доступа к процессу игры, запусти редактор от имени администратора.

## Что работает

**Игроки.** Поиск по имени и ID, фильтры по клубу, позиции, возрасту, потенциалу и сроку контракта. Цветные кнопки показывают молодых талантов, твой клуб и контракты, которые истекают в этом сезоне. В карточке игрока меняются все 118 полей таблицы `players`: атрибуты, общий рейтинг, потенциал, дата рождения, позиции, рабочая нога, финты, трейты, рост, вес, внешность.

**Контракты.** Зарплата, дата и срок контракта, роль в команде, бонусы. В базе FIFA 19 карьерные контракты есть только у игроков твоего клуба.

**Отступные.** Их можно посмотреть, изменить, добавить или убрать у любого игрока. В базе FIFA 19 их нет, игра держит отдельный список в памяти. Редактор находит этот список сам через 10–60 секунд после загрузки карьеры.

**Команды.** Название, трансферный бюджет на старте карьеры, престиж, цвета, капитан и исполнители стандартов. В карьере тренера ещё доверие совета и репутация тренера.

**Молодёжь.** Вкладка с юниорами из отчётов скаутов:
- правила: минимальные OVR и POT и рост. Каждого нового юниора редактор подтягивает под правила в течение 5 секунд, атрибуты растут вместе с рейтингом. После подписания в академию значения сохраняются;
- звёзды опыта и решения у скаутов, игра видит их сразу;
- точные OVR и POT в отчётах вместо вилки, для юниоров, найденных после включения. Этот режим ещё не проверен в игре.

**Без скаутинга.** На трансферном рынке игра показывает данные любого игрока без отчёта скаута. Включай до загрузки карьеры или перезагрузи её после включения.

**Тайм-финишинг.** Любой удар с тайм-финишингом засчитывается как идеальный, зелёный.

**Журнал и откат.** Каждая записанная правка попадает в журнал со старым значением и кнопкой «Вернуть». Правки атрибутов закрепляются: если игра после матча откатит значение (так она делает с твоим игроком в карьере игрока), редактор вернёт его, пока запущен.

Переключатели редактор запоминает и включает снова при следующем запуске игры.

## Что не работает и ограничения

- **Трансферный и арендный лист.** Игра хранит их вне базы. Поле «Статус» в контракте показывает, выставлен ли игрок, но изменить статус оттуда нельзя: игра его не перечитывает.
- **Трансферный бюджет по ходу карьеры** не найден. Поле в карточке команды действует только на старте карьеры.
- **Дата карьеры в шапке** отстаёт от игры: игра записывает текущую дату в базу только при сохранении. Возраст игроков считается от этой даты.
- **Отчёт скаута по кнопке** сделать не получилось. Дата в задании скаута означает конец задания, а не отчёт. Если её поменять, задание просто закончится.
- **Названия 7 полей FIFA 19** неизвестны. Имена полей взяты из меты FIFA 23, а этих полей там нет. В «Все поля» они подписаны кодами и выделены курсивом.
- **Отмены внутри игры нет.** Каждая запись сразу уходит в память игры. Сохраняй карьеру перед крупными правками.
- **Только Windows.** Редактор читает память процесса через WinAPI.

## Как это устроено

`le.py` — сервер на чистом Python без зависимостей. Он находит процесс `FIFA19.exe` и ищет в его памяти таблицы базы по общему маркеру. Поля таблиц он разбирает по их собственным описателям в памяти и пишет значения побитово. Интерфейс `index.html` — одна страница на HTML, CSS и JS без сборки.

Патчи кода меняют несколько байт в памяти `FIFA19.exe`, пока игра запущена. Перед записью редактор останавливает потоки игры. Файлы игры не меняются: после перезапуска игры всё на месте, и редактор ставит включённые патчи заново.
